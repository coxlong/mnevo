## 策略验收输入

向策略作用域加入一个仅适用于报表的流程，线索设为「导出」「源表」「核对」。在默认召回阈值 0.25 下，「导出图标」只有一个线索，分值约为 0.333，仍产生注入。三个独立的任务经本机管理员核实属于误注入后，后台生成一项阈值变更提案。批准前继续使用原版本。批准后阈值为 0.45，下一次任务的结果为 `no_match`。回滚发布新的版本后，相同查询再次注入。

## 已知实现范围

运行范围是 Linux 同账号的可信本机进程。复用依赖显式作用域，回查使用已登记的出处与摘录。自由文本条件会随记忆交付，自动过滤使用显式 `require`、`exclude`、作用域和有效期。诊断采用规则汇总，提案的发布证据需要本机用户核实。当前可学习提案处理数值策略，通用 LLM 的自动判定仍以研究报告口径核验为主。
